# Phishing Email Investigation Project

## Overview
This project demonstrates a basic SOC (Security Operations Center) style phishing email investigation. The objective was to analyze a suspicious email, identify phishing indicators, and document the findings in an incident response report.

---

## Objective
To investigate a suspicious email and identify indicators of phishing and social engineering attacks.

---

## Skills Learned
- Cybersecurity Fundamentals
- Threat Analysis
- Incident Response
- Phishing Detection
- Security Operations Center (SOC) Investigation

---

## Tools Used
- VS Code
- GitHub
- Manual Email Analysis

---

## Scenario
A suspicious email claiming to be from PayPal was analyzed for malicious indicators. The email attempted to pressure the recipient into clicking a fake verification link.

---

## Investigation Findings
The following phishing indicators were identified:

- Spoofed sender domain
- Suspicious verification link
- Urgent language intended to create panic
- Potential credential theft attempt
- Social engineering tactics

---

## Risk Level
High

---

## Recommended Actions
- Avoid clicking suspicious links
- Block malicious domains and senders
- Report phishing attempts to security teams
- Enable multi-factor authentication (MFA)
- Conduct user awareness training

---

## Conclusion
The email displayed multiple signs of phishing behavior and appeared to be an attempt to steal user credentials through social engineering techniques. This project helped demonstrate foundational SOC analyst skills related to email threat investigation and incident reporting.
